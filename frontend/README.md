# Ivory Timepieces

Contexte

Je souhaite créer une plateforme e-commerce moderne spécialisée dans la vente de montres en Côte d'Ivoire.

Le site doit inspirer confiance, être premium, rapide et optimisé pour mobile.

Le design doit être minimaliste, élégant et haut de gamme, dans un style inspiré d'Apple, Rolex et Daniel Wellington.

Couleurs :

Blanc

Noir

Gris clair

Accent Gold (#C9A227)

Le site doit être responsive.

Objectif

Permettre aux visiteurs de :

découvrir les montres

filtrer les produits

consulter les détails

ajouter au panier

commander

choisir leur mode de paiement

discuter via WhatsApp

suivre leurs commandes
